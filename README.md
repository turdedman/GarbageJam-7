


# Garbage Jam #7
Me and my bro make garbage game for garbagejam oooga boooooga <img width="128" height="128" alt="garbagejam7gamelogo" src="https://github.com/user-attachments/assets/3f4664ca-7aab-4408-8fd8-7c1425cefe1a" align="right"/>

Our garbage game's name is "Time's out", it features around a minute's gameplay, during which the player has to fix a clock in the base of an anti-hourwatch to prevent the world from going kaboom

### [The game's Itch.io page](https://naqe3b.itch.io/times-out)


## Controls

Scroll Wheel - camera zoom

W A S D - movement

Q - Drop (works only with boxes when you are on the clock)

Enter/Return - continue

Hovering over the hourglass makes it bigger and hovering over it again will make it small

And the player faces the cursor
